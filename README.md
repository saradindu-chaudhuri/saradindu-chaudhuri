* **Repo:** [Immunotherapy_Survival_ML](https://github.com/saradindu-chaudhuri/Immunotherapy_Survival_ML)
* **Focus:** Survival analysis & non-linear biomarker interactions in immunotherapy cohorts using Cox PH and Random Survival Forests.
* **Key Results:** 
  * Baseline Cox PH model achieved **0.710 C-Index** ($NLR$ $HR=1.16$, $CRP$ $HR=1.11$, $p < 0.005$).
